# Student Management System

## Overview
A console-based Student Management System developed in Python. It allows users to manage student records using file handling.

## Features
- Add Student
- View Students
- Search Student
- Delete Student
- Store records in a text file

## Technologies Used
- Python
- File Handling
- VS Code

## Project Structure
- main.py
- add_student.py
- view_students.py
- search_student.py
- delete_student.py
- database.py
- students.txt

## How to Run

```bash
python main.py
```
